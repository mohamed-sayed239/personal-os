# Personal OS

A personal management web application designed to help users organize their clients, track income and expenses, and monitor their daily business activities through a centralized dashboard.

## Overview

Personal OS provides a simple workspace for managing essential business and financial information in one place. It uses browser-based storage to keep user data available between sessions.

## Features

- **Dashboard:** A centralized overview of personal and business activities.
- **Client Management:** Organize and manage client information.
- **Income Tracking:** Record and track income transactions.
- **Expense Tracking:** Monitor and organize expenses.
- **Local Data Persistence:** Store application data using the browser's LocalStorage API.
- **Multi-Page Interface:** Separate pages for different management functions.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage API

## Architecture

The application uses a client-side architecture without a traditional backend server or external database. Data is stored locally in the user's browser through LocalStorage.
